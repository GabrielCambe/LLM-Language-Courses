# Spanish course: roadmap

**Goal:** reach a solid **A2** (introduce yourself, get around, shop, talk about past and future)
in about **5 months** at ~15 min/day, **alongside French**, then keep going to B1 mostly through
listening and conversation.

Spanish is the shortest road in this repo for a Brazilian: about 89% of the core vocabulary is
shared with Portuguese, and the grammar works almost the same way. So this roadmap doesn't teach
Spanish from zero. It teaches **the differences**: the sounds a Brazilian accent changes, the nouns
whose gender flips, the false friends and the handful of rules Portuguese doesn't have.

Each unit = **one rule family + ~15 high-frequency words + one output task**.

> 🌱 **Status: starter.** ✅ **Lesson pages: units 0–3** (marked ✅ below). The study app has decks
> for the same units and the Tutor knows the course. Generate the next lesson pages with
> [`../docs/unit-template.md`](../docs/unit-template.md) when you reach them, like the French units.

> 🧭 **Scope guard:** you only need the unit you're on and the next one. French is the main course:
> if French minutes start dropping, Spanish pauses first.

## 🤔 Why it feels easy (and the trap)

- **Why it feels easy:** Portuguese speakers understand Spanish much better than Spanish speakers
  understand Portuguese. Spanish has 5 vowels and no nasal ones; Portuguese has more of both. Your
  ear already handles the harder system, so Spanish sounds clear to you, while Portuguese sounds
  mumbled to them.
- **The trap: *portuñol*.** Because you can already be understood, it's easy to stop learning and
  speak Portuguese with Spanish endings. Those mistakes then *fossilise* (they become habits that
  are very hard to undo). The fix is to study the differences on purpose from day one, which is
  what this roadmap does.

## 🇫🇷🇪🇸 Running it alongside French

Learning two close languages at the same time works, but they leak into each other (*interference*):
*je suis* turns into *je sois*, or *pero* shows up in a French sentence. A few rules keep them apart:

1. **French stays the main course.** Spanish gets a **separate, shorter slot**: ~15 min, at a
   different time or place (e.g. French at your desk after lunch, Spanish on the commute).
   Memory is tied to context, so a different setting helps keep the languages apart.
2. **One language per session.** Don't switch mid-session. The Tutor chats are separate too.
3. **Don't start the same grammar topic in both in the same week** (e.g. French *passé composé*
   and Spanish *pretérito perfecto*), unless you compare them on purpose.
4. **Keep a mix-up list.** When a French word slips into Spanish (or the other way round), write the
   pair in the Today tab's parking lot. Comparing the three (FR / ES / PT) side by side is useful
   once a week.

## ⚠️ False friends (Portuguese → Spanish)

Words that look the same but mean something else. The deck adds them as they come up; this is the
cheat sheet.

| Spanish | Means | Portuguese look-alike means… | …which in Spanish is |
|---|---|---|---|
| *exquisito* | delicious | *esquisito* = weird | *raro* |
| *embarazada* | pregnant | *embaraçada* = embarrassed | *avergonzada* |
| *polvo* | dust | *polvo* = octopus | *pulpo* |
| *oficina* | office | *oficina* = workshop, garage | *taller* |
| *borracha* | drunk (f.) | *borracha* = eraser, rubber | *goma* |
| *rato* | a short while | *rato* = mouse, rat | *ratón / rata* |
| *apellido* | surname | *apelido* = nickname | *apodo* |
| *cena* | dinner | *cena* = scene | *escena* |
| *pronto* | soon | *pronto* = ready | *listo* |
| *todavía* | still, yet | *todavia* = however | *sin embargo* |
| *acordarse* | to remember | *acordar* = to wake up | *despertarse* |
| *largo* | long | *largo* = wide | *ancho* |
| *rojo* | red | *roxo* = purple | *morado* |
| *latir* | to beat (heart) | *latir* = to bark | *ladrar* |

## Notes
- 🌎 **Which Spanish?** Latin American first: *ustedes* for "you all", and *c/z* said as s. The
  course marks Spain (*vosotros*, the *th* sound) and Rioplatense (*vos*, *ll/y* as sh) when they
  come up. Learn to *recognise* *vosotros* forms; you don't need to produce them.
- 🔊 **Audio** uses a Mexican Spanish voice when your device has one, and any Spanish voice otherwise.
- ⌨️ **Typing:** ¿ and ¡ are optional in the flashcards; the accent keys have them plus á é í ó ú ñ ü.
- **Resources:** *Dreaming Spanish* (YouTube, comprehensible input sorted by level, start at
  "superbeginner" for listening speed, not for the words); the *Españolistos* podcast for easy
  conversation; a textbook like *Aula Internacional* if you want a printed spine.
- 🎵 **Music to start with** (clear diction): Natalia Lafourcade (Mexico), Jorge Drexler (Uruguay).
  Reggaeton is great motivation but full of Caribbean slang: save it for the Song Workshop later.
