# Unit 3: Having and describing: *tener*, *hay*, *muy* vs *mucho* · CEFR A1 · ~7 days

## 🎯 Can-do goals
- I can say what I have, how old I am, and how I feel (*tengo hambre, tengo sueño*).
- I can say what there is in a place with *hay*.
- I can describe things with adjectives that agree, and never mix up *muy* and *mucho*.

## 📐 The rule

### *Tener* (to have)

| | Spanish | Portuguese |
|---|---|---|
| I have | **tengo** | tenho |
| you have (*tú*) | **tienes** | tens |
| he / she has, you have (*usted*) | **tiene** | tem |
| we have | **tenemos** | temos |
| you all have (Spain) | **tenéis** | tendes |
| they have, you all have | **tienen** | têm |

The *e → ie* in *tienes, tiene, tienen* is a preview of Unit 5 (stem-changing verbs).

### Feelings with *tener*, not *estar com*

| Spanish | Portuguese | English |
|---|---|---|
| tener **hambre** | estar com fome | to be hungry |
| tener **sed** | estar com sede | to be thirsty |
| tener **frío / calor** | estar com frio / calor | to be cold / hot |
| tener **sueño** | estar com sono | to be sleepy |
| tener **prisa** | estar com pressa | to be in a hurry |
| tener **miedo** | ter medo | to be afraid |
| tener **razón** | ter razão | to be right |
| tener **30 años** | ter 30 anos | to be 30 |
| tener **que** + infinitive | ter que | to have to |

### *Hay*: there is / there are
- Existence = ***hay***, the same for singular and plural: *Hay un banco cerca. Hay muchos restaurantes.*
- Brazilians say *tem* for this. In Spanish it's **always *hay***, never *tiene*.
- *Hay* goes with *un/una*, numbers or no article, **not *el/la***: *Hay un banco* ✅ · *Hay el banco* ❌
  → for a specific thing, say where it is: *El banco **está** en la esquina* (*estar*: Unit 6).
- Questions: *¿Hay wifi? ¿Hay un supermercado por aquí?*

### *Muy* vs *mucho*

| | Use | Examples |
|---|---|---|
| **muy** | before **adjectives and adverbs** | *muy grande, muy bien, muy lejos* |
| **mucho / mucha / muchos / muchas** | before **nouns** (agrees with them) | *mucho tiempo, mucha gente, muchos libros* |
| **mucho** | **after verbs** | *Trabajo mucho. Me gusta mucho.* |
| **mucho** | before *mejor, peor, más, menos* | *mucho mejor*, never *muy mejor* |

### Adjectives agree, and usually go after the noun
- **-o**: *rojo, roja, rojos, rojas*
- **-e** or a **consonant**: same for both genders: *grande, grandes* · *azul, azules*
  (but nationalities add -a: *español → española*)
- Usually **after** the noun: *una casa grande, un coche rojo*.
- A few shorten before a singular noun: *bueno → **buen** libro*, *malo → **mal** día*,
  *grande → **gran***, which changes the meaning: *una gran ciudad* (a great city) vs
  *una ciudad grande* (a big city).

## ⚠️ Common traps
- ❌ *Estoy con hambre* → ✅ ***Tengo** hambre*
- ❌ *Tiene un banco cerca* (meaning "there is") → ✅ ***Hay** un banco cerca*
- ❌ *mucho grande* → ✅ ***muy** grande* · ❌ *muy gente* → ✅ ***mucha** gente* · ❌ *muy mejor* → ✅ ***mucho** mejor*
- ❌ *Tengo mucho hambre* → ✅ *Tengo **mucha** hambre* (hambre is feminine: *el hambre*, Unit 2)
- ⚠️ **False friends:** ***rojo*** = red (purple is *morado*), ***largo*** = long (wide is *ancho*).

## 💡 Curiosity
***Hay*** is two words glued together: ***ha*** (has) + an old ***y*** meaning "there" (from Latin
*ibi*). So it's literally "it-there-has"… which is exactly French ***il y a***! The *y* in *hay* and
the *y* in *il y a* are the same word. Your French and Spanish are helping each other here.
