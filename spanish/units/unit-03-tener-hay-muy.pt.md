# Unidade 3: Ter e descrever: *tener*, *hay*, *muy* vs *mucho* · QECR A1 · ~7 dias

## 🎯 Objetivos
- Consigo dizer o que tenho, quantos anos tenho e como estou (*tengo hambre, tengo sueño*).
- Consigo dizer o que há num lugar com *hay*.
- Consigo descrever coisas com adjetivos que concordam, e nunca confundo *muy* e *mucho*.

## 📐 A regra

### *Tener* (ter)

| | Espanhol | Português |
|---|---|---|
| eu tenho | **tengo** | tenho |
| você tem (*tú*) | **tienes** | tens |
| ele / ela tem, o senhor tem (*usted*) | **tiene** | tem |
| nós temos | **tenemos** | temos |
| vocês têm (Espanha) | **tenéis** | tendes |
| eles têm, vocês têm | **tienen** | têm |

O *e → ie* de *tienes, tiene, tienen* é uma prévia da Unidade 5 (verbos com mudança no radical).

### Sensações com *tener*, não com *estar com*

| Espanhol | Português |
|---|---|
| tener **hambre** | estar com fome |
| tener **sed** | estar com sede |
| tener **frío / calor** | estar com frio / calor |
| tener **sueño** | estar com sono |
| tener **prisa** | estar com pressa |
| tener **miedo** | ter medo |
| tener **razón** | ter razão |
| tener **30 años** | ter 30 anos |
| tener **que** + infinitivo | ter que |

### *Hay*: há, tem
- Existência = ***hay***, igual no singular e no plural: *Hay un banco cerca. Hay muchos restaurantes.*
- Os brasileiros dizem *tem* para isso. Em espanhol é **sempre *hay***, nunca *tiene*.
- *Hay* vai com *un/una*, números ou sem artigo, **não com *el/la***: *Hay un banco* ✅ · *Hay el banco* ❌
  → para uma coisa específica, diga onde ela está: *El banco **está** en la esquina* (*estar*: Unidade 6).
- Perguntas: *¿Hay wifi? ¿Hay un supermercado por aquí?*

### *Muy* vs *mucho*

| | Uso | Exemplos |
|---|---|---|
| **muy** | antes de **adjetivos e advérbios** | *muy grande, muy bien, muy lejos* |
| **mucho / mucha / muchos / muchas** | antes de **substantivos** (concorda com eles) | *mucho tiempo, mucha gente, muchos libros* |
| **mucho** | **depois de verbos** | *Trabajo mucho. Me gusta mucho.* |
| **mucho** | antes de *mejor, peor, más, menos* | *mucho mejor*, nunca *muy mejor* |

🇧🇷 O português usa "muito" para tudo; o espanhol divide em dois: "muito grande" = *muy grande*, "muita gente" = *mucha gente*.

### Os adjetivos concordam, e em geral vêm depois do substantivo
- **-o**: *rojo, roja, rojos, rojas*
- **-e** ou **consoante**: igual para os dois gêneros: *grande, grandes* · *azul, azules*
  (mas as nacionalidades ganham -a: *español → española*)
- Em geral **depois** do substantivo: *una casa grande, un coche rojo*.
- Alguns encurtam antes de um substantivo no singular: *bueno → **buen** libro*, *malo → **mal** día*,
  *grande → **gran***, o que muda o sentido: *una gran ciudad* (uma grande cidade, importante) vs
  *una ciudad grande* (uma cidade grande, de tamanho).

## ⚠️ Armadilhas comuns
- ❌ *Estoy con hambre* → ✅ ***Tengo** hambre*
- ❌ *Tiene un banco cerca* (no sentido de "há") → ✅ ***Hay** un banco cerca*
- ❌ *mucho grande* → ✅ ***muy** grande* · ❌ *muy gente* → ✅ ***mucha** gente* · ❌ *muy mejor* → ✅ ***mucho** mejor*
- ❌ *Tengo mucho hambre* → ✅ *Tengo **mucha** hambre* (hambre é feminino: *el hambre*, Unidade 2)
- ⚠️ **Falsos amigos:** ***rojo*** = vermelho (roxo é *morado*), ***largo*** = comprido (largo é *ancho*).

## 💡 Curiosidade
***Hay*** são duas palavras grudadas: ***ha*** (tem, de *haber*) + um antigo ***y*** que queria dizer "ali" (do latim
*ibi*). Então é literalmente "ali-há"… que é exatamente o francês ***il y a***! O *y* de *hay* e
o *y* de *il y a* são a mesma palavra. O seu francês e o seu espanhol estão se ajudando aqui.
(E o português tem o mesmo *haver*: "há um banco perto".)
