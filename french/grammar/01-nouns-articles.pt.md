# Substantivos e artigos

## Gênero
Todo substantivo é **masculino** ou **feminino**. Aprenda cada substantivo **com o seu artigo**.

### Regras de terminação (≈ 80% confiáveis)

| Geralmente masculino | Geralmente feminino |
|---|---|
| -age, -ment, -eau, -isme, -oir, -et, -al, -ail, -eil | -tion, -sion, -té, -ette, -ure, -ence, -ance, -ie, -ade, -esse, -ude, -ée |

**Exceções para decorar:** *la page, la plage, l'image, la cage, la nage* · *l'eau, la peau* ·
*le silence* · *le musée, le lycée*. Para muitas palavras comuns nenhuma regra se aplica (*la mer, le lait,
la main, le pied*), então é só aprender com o artigo.

🇧🇷 **Cuidado com o português:** o gênero muitas vezes coincide (*la table* = a mesa), mas não sempre. As palavras em **-age**
são masculinas em francês e femininas em português (*le voyage* = a viagem, *le message* = a mensagem), e
*la mer* (o mar), *le lait* (o leite... aqui coincide!), *la dent* (o dente), *le sang* (o sangue) pedem atenção.

### Pessoas
Muitos substantivos para pessoas têm forma feminina:
*un ami / une amie · un étudiant / une étudiante · un acteur / une actrice · un chanteur / une chanteuse ·
un musicien / une musicienne · un développeur / une développeuse*.
Alguns não mudam: *un/une élève, un/une journaliste, un/une artiste*.

## Artigos

| | m. sing. | f. sing. | antes de vogal/h | plural |
|---|---|---|---|---|
| definido (o, a) | le | la | l' | les |
| indefinido (um, uma, uns) | un | une | un / une | des |
| partitivo (um pouco de, incontável) | du | de la | de l' | des |

### Qual usar?
- **Definido (*le/la/les*):** uma coisa específica (*le livre sur la table*) **ou uma categoria geral**
  (*J'aime le chocolat. Les chiens sont fidèles.*). Verbos de gostar/não gostar (*aimer, adorer,
  détester, préférer*) quase sempre levam o artigo definido.
- **Indefinido (*un/une/des*):** uma (ou várias) coisa(s) contável(eis): *un café, des amis*.
- **Partitivo (*du/de la/de l'*):** uma quantidade não especificada de algo **incontável**:
  *Je bois **du** café. Il mange **de la** soupe. Tu veux **de l'**eau ?*
  🇧🇷 O português não usa nada aqui ("bebo café", "quer água?"), mas o francês **exige** o partitivo: ❌ *Je bois café.*

### Depois da negação: *un/une/des/du/de la* → **de / d'**
*J'ai un chat. → Je n'ai pas **de** chat.*
*Je bois du café. → Je ne bois pas **de** café.*
**Exceto com *être*:** *C'est un chat. → Ce n'est pas **un** chat.*
Os artigos definidos nunca mudam: *J'aime le café → Je n'aime pas **le** café.*

### Depois de quantidades: **de**
*beaucoup **de** gens, un peu **de** sucre, une bouteille **d'**eau, un kilo **de** pommes, trop **de** travail.*

## Plural

| Regra | Exemplo |
|---|---|
| + **s** (mudo) | *le livre → les livres* |
| -s, -x, -z: não muda | *le pays → les pays, le prix → les prix* |
| -eau, -eu → + **x** | *le bateau → les bateaux, le jeu → les jeux* |
| -al → **-aux** | *le journal → les journaux, le cheval → les chevaux* (como jornal → jornais) |
| -ail → -aux (alguns) | *le travail → les travaux* |
| irregular | *l'œil → les yeux* (olho/olhos) |

💡 *les yeux* se pronuncia "lê-**z**iö" (liaison), então você vai ouvir "*tes yeux*" como "tê-ziö".
