# Curso de latim: roteiro

**Objetivo:** ler sozinho latim fácil e de verdade (primeiro textos adaptados, depois autores como César e os trechos
mais fáceis de Ovídio) em uns **6 meses**, com ~25 min/dia.

O latim se aprende principalmente para **ler**, então este curso se apoia em muita leitura fácil
(o método de Hans Ørberg em *Lingua Latina per se illustrata*) em vez de decorar
tabelas soltas. A grafia clássica com **mácrons** (ā, ē, ī…) e a pronúncia clássica
restaurada são usadas o tempo todo.

> 🌱 **Situação: inicial.** ❌ **Ainda sem páginas de lição: este roteiro é tudo o que existe.** O app de estudo tem
> baralhos para as unidades 0–3 e o Tutor conhece o curso. Gere cada página de lição com o
> [`../docs/unit-template.pt.md`](../docs/unit-template.pt.md) quando chegar nela, como as unidades de francês.

> 🧭 **Guarda de escopo:** você só precisa da unidade em que está e da próxima.

## Notas
- 🔊 **Áudio:** não existem vozes de latim para síntese de voz, então o app usa uma voz **italiana**.
  Ela soa como o latim eclesiástico, não o clássico: no latim clássico o *c* é sempre "k" (*Cicero* = "KI-ke-ro",
  não "TCHI-tche-ro") e o *v* é o *u* de *água*.
- 🇧🇷 **Hábitos brasileiros para largar:** o *s* entre vogais continua s (*rosa* = "RÓ-sa", não "RÓ-za"), *ti / di* continuam
  "ti / di" (nunca "tchi / dji"), e os *-e / -o* finais ficam inteiros (*mare*, *dominō*). O *-m* final do latim clássico
  provavelmente só nasalizava a vogal anterior, como no *bem* do português: *rosam* ≈ "RÓ-sã".
- **O português ajuda muito:** o português nasceu do latim falado, então muitas palavras são reconhecíveis
  (*aqua* → água, *terra* → terra, *fīlia* → filha). Aproveite, mas cuidado com os falsos amigos.
- **Recursos:** Ørberg, *Lingua Latina per se illustrata* (pars I: *Familia Rōmāna*) como leitura principal;
  *Wheelock's Latin* como referência gramatical (em inglês). Em português, a *Gramática Latina* de Napoleão Mendes de Almeida é um clássico de referência.
